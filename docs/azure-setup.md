# Azure Setup – Untangle Shop

## Overview

This document describes the Azure resources provisioned for the Untangle Shop project as part of Week 5. The objective was to understand Azure cloud services and provision the required infrastructure without deploying the application.

---

# Azure Subscription

- Subscription: Azure for Students
- Cloud Provider: Microsoft Azure
- Region: Central India

---

# Resource Group

**Name:** `untangle-shop-rg`

The Resource Group acts as a container that organizes all Azure resources related to the Untangle Shop project.
